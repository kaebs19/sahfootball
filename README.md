## المكوّنات

| المجلد | ما فيه |
|---|---|
| `server/` | Node + Express + PostgreSQL + Redis — الـ API والموقع العام |
| `admin/` | React + Vite — لوحة التحكم (تُخدم على `/admin`) |
| `web/` | أصول الموقع العام (CSS والأيقونة) |
| `mobile/` | Flutter — تطبيق iOS و Android |

الأربعة منتج واحد بهوية بصرية واحدة: نفس الألوان والخطوط وقواعد
الاستعمال في كل واجهة.

## التشغيل محلياً

يتطلب Node 20+ و PostgreSQL و Redis.

```bash
cd server
npm install
cp .env.example .env          # املأ DATABASE_URL و JWT_SECRET
npm run migrate
npm run dev
```

للتجربة بلا مفتاح مزوّد، اضبط `USE_SAMPLES=true` — يقرأ من
`server/samples/` بلا أي نداء خارجي.

لوحة التحكم في طرفية أخرى:

```bash
cd admin && npm install && npm run dev
```

تطبيق الجوال:

```bash
cd mobile && flutter run --dart-define=API_URL=http://localhost:3000
```

للنشر على سيرفر: **[DEPLOY.md](DEPLOY.md)**.

## قرارات معمارية تستحق المعرفة

**طبقات صارمة في السيرفر.** `routes/` تفهم HTTP فقط، و`repositories/`
تملك كل SQL، و`services/` تتولى المنطق والتعامل الخارجي. لا SQL في
مسار أبداً.

**عزل المزوّد.** كل نداء لـ API-Football يمر عبر
`services/footballProvider.js` خلف كاش Redis وعدّاد حصة يومية —
الخطة المجانية 100 طلب/يوم، فكل قرار مزامنة محكوم بسؤال "كم يكلّف؟".

**الموقع العام يُصنع في السيرفر بلا JavaScript.** رابط سياسة
الخصوصية شرط في مراجعة App Store ويجب أن يصل مكتوباً في أول بايت،
لا بعد نداء شبكة.

**محتوى الصفحات Markdown لا HTML.** يُهرَّب من HTML أولاً ثم تُطبَّق
مجموعة صغيرة من Markdown — لولا ذلك لصار أي حساب أدمن مخترق ثغرة
XSS دائمة على كل زائر.

**الإيقاف يُفحص في كل طلب.** استعلام إضافي مقصود: الفحص عند الدخول
وحده يترك الموقوف يعمل حتى ١٥ دقيقة بتوكنه الحالي، وإيقاف يبدأ
مفعوله بعد ربع ساعة ليس إيقافاً.

**الإعداد يُفحص قبل الإقلاع.** السيرفر يرفض العمل في الإنتاج بسر
توقيع ضعيف أو ببيانات تجريبية — الانهيار الصاخب أرحم من ثغرة صامتة.

## الحالة

جاهز: المصادقة، التوقعات والنقاط، المجموعات، تعدد الدوريات، لوحة
التحكم الكاملة، الموقع العام، إدارة الحسابات.

ينقص قبل الإطلاق: اشتراك مدفوع في مزوّد البيانات (الخطة المجانية
لا تخدم الموسم الحالي)، ومزوّد بريد حقيقي، والاشتراكات داخل
التطبيق.
